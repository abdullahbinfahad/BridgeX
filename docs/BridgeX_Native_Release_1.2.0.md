# BridgeX Native Release 1.2.0

The independent native BridgeX application was built through Expo EAS on 22 August 2026 using Expo SDK 57. It replaces the former WebView wrapper with native screens while retaining the existing secured backend API.

| Artifact | Build ID | Status | Version |
|---|---|---|---|
| Internal Android APK | `0f46f5a6-7656-4096-b8e2-a7f352b96165` | Finished | `1.2.0 (13)` |
| Play Store Android App Bundle | `1106a949-6e1a-44a0-92c9-d43c48966cac` | Finished | `1.2.0 (13)` |

The signed APK is available for internal distribution for 13 days from the build page. The signed AAB is available for Play Console upload for 29 days from the build page. Before publishing an AAB to an existing Google Play listing, the owner must confirm that the Play Console accepts the signing lineage and package identifier `im.bridgex.marketplace`.

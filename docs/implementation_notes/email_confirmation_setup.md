# BridgeX Email Confirmation Setting

On 2026-08-21, Supabase Dashboard → BridgeX project → Authentication → Sign In / Providers was updated so **Confirm email** is enabled. The setting persisted after a page reload.

New email-password registrations now receive Supabase’s confirmation email and must confirm the address before their first password sign-in. The BridgeX registration page redirects confirmation links back to `/access` and explains this step to new members.

# BridgeX

## Cross-Border Traveler Delivery Marketplace

BridgeX is a secure marketplace that connects travelers and senders between Bangladesh and China. The platform enables users to publish delivery requests, offer available luggage space during travel, receive competitive offers, and complete deliveries through a trusted and verified workflow.

---

## Mission

To make international personal delivery between Bangladesh and China safer, easier, faster, and more affordable through a trusted community-driven platform.

---

## Vision

To become the leading cross-border traveler delivery marketplace, connecting international students, travelers, and communities worldwide through secure and transparent logistics.

---

## Core Features

* User Registration & Authentication
* Identity Verification
* Delivery Request Posting
* Flight & Travel Listing
* Offer / Bidding System
* Real-Time Messaging
* Escrow-Based Payment Workflow
* Reviews & Ratings
* Notifications
* Admin & Moderator Dashboard
